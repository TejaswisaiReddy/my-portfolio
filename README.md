# Sai Tejaswi — UX & Product Designer Portfolio

**Live site: https://saitejaswi-portfolio.netlify.app/**

Static portfolio site. No build step: open `index.html` in a browser, or deploy the repository root to any static host (Netlify, Vercel, GitHub Pages).

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home |
| `tiny-treasures.html` | Case study 01 — Tiny Treasures ([live app](https://tiny-treasures-mu.vercel.app/)) |
| `pickde.html` | Case study 02 — Pickde |
| `nokia.html` | Case study 03 — UX/UI Trainee at Nokia |
| `food-delivery.html` | Practice project — Food delivery app |

## Other files

- `site.js` — prototype walkthrough, screen viewer, tabs, copy-email
- `images/` — all screens (WebP)
- `Sai-Tejaswi-Muthukuri-CV.pdf` — CV, linked from the footer

## Deployment

The live site is hosted on Netlify and deploys from the `main` branch of this repository. `netlify.toml` tells Netlify there is no build step and to publish the repository root. Every push to `main` updates https://saitejaswi-portfolio.netlify.app/.
